## 8. Remaining risks and next actions

1. **Original uploads keep their EXIF, including any GPS location, and are served once public.** This is existing, intentional behaviour, unchanged here. If location privacy is required, the owner must decide whether to strip GPS from stored originals; that's a product change, not part of this upgrade.
2. **Not exercised locally:** the first CI run on `ubuntu-latest` with `npm ci` will be the first check that the `linux-x64` binaries load on that platform.
3. **Remaining advisories (out of scope):** Vitest 3 → 5 (dev only) and Prisma 6 → 7 (CLI config); each needs its own batch.
4. **Note:** the local `.next` build was made against the isolated test DB. Rebuild before running `next start` against another database.
